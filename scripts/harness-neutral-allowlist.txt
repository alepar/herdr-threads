# Allowlist for scripts/check-harness-neutral (the harness-neutral core seam, root spec section 1).
#
# One entry per line, sorted (byte order) and unique:
#     <path>:<pattern> — <category>: <text>
# <path> is repo-relative. <pattern> is a fixed string (no regex): an entry allows a harness-naming
# token T in file <path> when the pattern contains T and occurs on the same source line (comments
# removed). A bare-token pattern (`claude`) allows that token anywhere in the file; a longer
# pattern (`registry.agent("claude")`) allows it only on lines containing that text. The separator
# is space, U+2014 EM DASH, space (the first one after the first `:`); <text> must be non-empty.
# An entry that no longer covers any site is stale and fails the check, so a leaf that migrates a
# site deletes its entry in the same commit. Keep the file sorted: leaves then edit disjoint hunks.
#
# Categories:
#   to-migrate   temporary. The owning leaf named in <text> moves the site behind the adapter
#                contract and deletes the entry; ht-poh.2.8 makes any remaining to-migrate entry a
#                hard failure.
#   frozen-wire  a frozen v1 wire shape (HarnessHealth / HarnessEvidence / HookParseFailure, legacy
#                contract ids, the not_claude wire code). May stay permanently.
#   history      a historical schema migration shape. May stay permanently.
#   registration the builtins() rows, the CODEX / CLAUDE registry identities, the OccupantHarness /
#                context::Harness consts and the harness/mod.rs `pub mod` lines. May stay permanently.
#
# Only frozen wire shapes, historical migrations and registration may stay permanently (root spec
# section 1); everything else is to-migrate. A site in a file outside core-sweep D15 is marked
# `unassigned` until the coordinator routes it.
