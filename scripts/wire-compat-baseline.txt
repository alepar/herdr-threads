# Peer wire baseline for scripts/check-wire-compat: the wire fields and gated-enum variants that
# existed before the lint (the shapes every released peer already decodes).
#
# Format: `field <Type>.<field>` / `field <Enum>::<Variant>.<field>` / `variant <Enum>::<Variant>`,
# sorted (byte order) and unique; `#` and blank lines only in this header.
# Regenerate with `scripts/check-wire-compat --suggest` (then keep this header).
#
# Policy: the baseline grows only by NEW types (e.g. `OpaqueWire`), in the commit that
# introduces them. Never baseline a new field of an existing type: give it `#[serde(default)]`.
# Never baseline a new gated variant: mark it `// cap: <CONST>` (a pub const in src/sync/frame.rs).
# A line matching nothing in the tree is stale and fails the check.
