# Development history

[`herdr-threads-run/`](herdr-threads-run/report.md) holds the closing records of the run that built herdr-threads: the final [report](herdr-threads-run/report.md), the [run log](herdr-threads-run/run.md), [friction notes](herdr-threads-run/friction.md), the PR roast reports, the parked-findings disposition and the upstream feedback draft. The designs they implement are in [`docs/design/`](../design/).

These records name many working files of the run (reviews, assessments, logs, evidence folders) by path. Those files are archived in git tag `archive/herdr-threads-run-2026-09-26` under `docs/superpowers/runs/2026-09-26-herdr-native-mailbox-thread-plugin/` (path unchanged there); the few that code, tests or docs need are kept in [`docs/evidence/`](../evidence/README.md).

[`remaining-findings-run/`](remaining-findings-run/report.md) holds the closing records of the run that closed the [remaining findings](remaining-findings-2026-10-01.md) (B1–B4, B6–B10): the [report](remaining-findings-run/report.md), the [run log](remaining-findings-run/run.md), [friction notes](remaining-findings-run/friction.md), the design and PR roast reports with their step-backs, the coverage ledger, the graph-pass judgement, the [findings closure ledger](remaining-findings-run/findings-closure.md) with its checker (`python3 docs/history/remaining-findings-run/findings-closure-check.py`), the integration sweep notes, the smoke records, the native rerun results (`native-rerun.json`, cited by [`docs/validation/report.md`](../validation/report.md)) and the upstream feedback draft. Its specs are in [`docs/design/herdr-threads/remaining-findings/`](../design/herdr-threads/remaining-findings/2026-10-01-remaining-herdr-threads-findings-design.md). Working files these records name but that are not kept (coverage packs and trees, roast-design trees, graph-pass dumps, the native rerun matrix log, process-leak evidence) are archived in git tag `archive/remaining-findings-run-2026-10-01` under `docs/superpowers/runs/2026-10-01-remaining-herdr-threads-findings/` (path unchanged there).
