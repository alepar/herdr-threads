Rejected 3/3: request_id already created and locked <key>.lock earlier in the same run (line 205), so reopening it at settle needs no new space and the EDQUOT trigger cannot apply; remove_file errors were already discarded on base; a stale Refused/NoCap/Failed record replays the same idempotent answer on rerun.
