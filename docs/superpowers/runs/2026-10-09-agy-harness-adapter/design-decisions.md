# agy harness adapter — design decisions (root brainstorm, Mode A, 2026-10-09)

Working notes from the interactive brainstorm; the spec supersedes this file once written.

1. Enrollment: global hook enrollment like Claude/Codex (not launch-only like Hermes). Bare `agy` in a Herdr pane enrolls on first prompt.
2. Child vs /clear: a SessionStart is top-level only if `presence/<id>.lock` exists AND the pane's bound conversation does not list `<id>` under `brain/<bound>/.system_generated/subagents/`. Otherwise child: no seat change, child restriction answered locally. Hook gathers facts as evidence; daemon decides (A2). A missed /clear rebinds at the next turn-start PreInvocation re-check. TRUST-POLICY gains the on-disk witness rule.
3. Shell permission: setup owns one `command(herdr-threads)` entry in `~/.gemini/antigravity-cli/settings.json` `permissions.allow` via the shared JSON engine (owned array member, manifest, pre-existing kept). Status/doctor report a missing entry (agy rewrites this file). `--sandbox` socket reachability: documented/doctor-informational limit, no launch refusal.
4. Install shape: owned plugin directory `~/.gemini/config/plugins/herdr-threads/` (plugin.json + hooks.json) written by setup as owned assets (not `agy plugin install`); no `rules/` file; status reports disabled state from `config/config.json`.
5. Delivery: reuse v0.5.0 Claude-mod daemon delivery (D4 framing, paging, ack-by-id, routing suppression) with the agy hook acting as a pull-based mod: PreInvocation (every invocation) checks attention version, injects framed full bodies (injectSteps toolCall if the 1.3.2 probe passes, else userMessage). Idle: existing native wake; the woken turn's PreInvocation delivers. Settlement is transcript-confirmed: the next hook call verifies the injected ids in `transcriptPath` before acking, under a new sibling provenance (e.g. `cooperative_hook_delivery`, TRUST-POLICY). Lazy rows ride along. Expect generalization of Claude-specific v0.5.0 pieces (watch --harness claude, not_claude, harness='claude' checks) — record for the adapter-model report.

Side work: Hermes global enrollment split to bead ht-4ne, tab `hermes-global`.
6. Testing, three tiers: (1) fixture tests in CI from recorded agy 1.3.2 hook payloads and on-disk layouts, no binary; (2) opt-in model-free native gate (`HT_AGY_BIN`) with the genuine binary against our scripted fake Gemini server in `scripts/` (Python); (3) live smoke once at the final SHA via a thin relay we write (replaces LiteLLM and the shim) to OpenRouter `google/gemini-2.5-flash`, cap ≤40 requests / ≤$0.50 enforced in the relay, key read only locally from `~/.hermes/.env` (never in GitHub CI). Live tests stay out of CI for every harness (follow-up bead: live tests for all harnesses).
5a. Probe 2026-10-09: `injectSteps` toolCall is broken on 1.3.2 and 1.3.3 (internal_only and deprecated; aborts the turn). Delivery uses the undocumented `{"systemMessage":{"systemMessage":"..."}}` step: permanent, agy-labelled as hook-injected and not from the user, invisible in the TUI. Pinned by the version ladder and verified by the native gate. The hook emits only step types verified for that version: a well-formed unsupported step aborts the turn, and malformed output is silently dropped along with any sibling steps.
4a. agy has on-demand skills: the plugin ships `skills/herdr-threads/SKILL.md` (listed by name and path in the system prompt; the body is read through view_file).
7. In scope, ComposerPolicy (idle wake): parse agy's prompt box from Herdr `agent read --source detection` into empty, draft or unreadable, from model-free private-tmux TUI captures used as fixtures. `composer_stash` and `poke_during_turn` start Unsupported, so wake only into an empty box on an idle agy. Without a policy, wake never fires (read_composer_text returns Unreadable).
   In scope, LaunchPolicy (launch/handoff --kind agy): model flags; resume via `--conversation <id>`; refuse `-p`, `--dangerously-skip-permissions` and `--sandbox` (at launch only); optional `HERDR_THREADS_AGY_OPTS`.
8. agy updates: no version gate (versionless policy). Default `systemMessage`; the Stop hook (terminationReason/error) detects an injection-caused abort and records it against the agy executable identity. Later injections use documented `userMessage` for that installation; doctor shows it, and a new executable identity retries systemMessage. The witnesses fail safe on their own (everything looks like a child); doctor flags "SessionStart without witness".
9. Delivery contract (core, documented in AGENTS.md; goal: token efficiency). Lazy is the default. Lazy never wakes an idle session. Turn hooks and channels deliver every pending item (lazy or not) directly, avoiding extra herdr-threads calls. A nudge wakes only an idle session; a spinning session (tool or generation) gets no nudge. ACK-required messages always count as nudges. The policy method `idle_wake() -> Native | Channel` replaces suppress-wake: it says who performs the idle wake. Bead 1 includes an audit of the code against these rules.
10. In scope: a per-seat runtime opt-in `wake_on: nudge | all` (wake on any message, lazy included), for coordinator or mod seats that must react to everything. It is harness-neutral (core wake decision) and advertised in the herdr-threads SKILL: how to enable it, and when it is appropriate.
11. Hook failure handling: on any internal error the hook prints nothing and exits 0 (PreInvocation fails open). It emits only verified step types and well-formed JSON, with shapes locked by fixtures. It uses the 1.5 s tool-hook budget; the nothing-new path is one attention-version round trip. No PreToolUse hook. When the daemon is down: no output. Doctor reports: plugin disabled, missing allow entry, systemMessage downgrade, SessionStart without a witness, the --sandbox limit.
12. Harness-neutral core: an AGENTS.md rule (all harness-specific code goes behind HarnessAdapter and its policy traits in src/harness/<id>/), enforced by scripts/check-harness-neutral plus an allowlist that records a reason per entry (frozen wire shapes, history migrations, builtins()). The sweep is total. Claude's v0.5.0 mod is re-fitted onto DeliveryPolicy (PushChannel) byte-identically. agy is HookPull. Split: (1) neutral rule, check and contract audit; (2) total core sweep, by area; (3) DeliveryPolicy and the Claude mod re-fit; (4) the agy adapter minus delivery; (5) agy HookPull delivery; (6) test infra (fake Gemini server, native gate, relay, live smoke). wake_on goes with (3).
