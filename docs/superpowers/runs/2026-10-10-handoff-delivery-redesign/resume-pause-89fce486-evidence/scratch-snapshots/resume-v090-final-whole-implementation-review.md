## F1 — A standalone-unrenderable normal message permanently blocks normal delivery

Severity: material/P2. The normal source can save an item which cannot fit a standalone 65536-byte presentation, then return endless continuation without advancing it. Later ordinary/Lazy items remain behind that carry. A capable Watch caller immediately repeats the RPC while `more` is true.

Primary defect: `src/store/invitation_content.rs:2630` breaks on a failed trial measurement without distinguishing a full page from an item that cannot fit an empty page. `shown_message_count` remains unchanged, and lines 2716–2719 persist the same head. `ordinary_runnable` at lines 2029–2042 treats any retained carry as runnable at positive capacity. The `had_carry` guard in the normal-source admission prevents another fresh ordinary walk until this carry is consumed. The carry retains its original marker prefix, so supplying a shorter prefix on the next request does not repair it.

Concrete admitted canonical input:

1. Use a live registered Watch presentation lease and an otherwise empty logical offer ledger, with positive capacity.
2. Publish a canonical addressed Lazy message with `format!("{}é", "\0".repeat(65534))`, exactly 65536 UTF-8 bytes. A full ordinary addressed message also exhibits the sizing condition, with two continuation commands instead of one.
3. Issue public `DeliveryPullV2` with eight marker arguments each containing 512 NUL characters. `src/protocol/delivery.rs:12–36` allows eight arguments and 4096 total raw bytes; V2 delegates to that validation and imposes no control-character restriction. This is the same body/prefix geometry deliberately admitted by the existing due-path regression at `tests/service/delivery_pull.rs:11704`.
4. The assembler retains the first 8192 raw body bytes (`src/delivery/assemble.rs:285–324`). JSON encodes those NULs as six bytes each: 49152 bytes. The Lazy continuation embeds the marker prefix once (`src/protocol/watch.rs:110–132`). Shell quoting encodes each NUL as four characters, including one backslash (`src/protocol/output.rs:591` onward); JSON adds another backslash, hence at least 20480 bytes for the prefix. The singleton therefore exceeds **69632 encoded bytes before any metadata or framing**, above the 65536-byte output bound. Ordinary output has two such commands and is larger still.
5. `src/delivery/presentation.rs:239–274` measures the actual Watch JSON lines. The same bound applies to the registered JSON-string Hook envelope: `src/delivery/frame.rs:55–89` preserves the NUL body characters. The source fitter rejects the item rather than emitting an over-limit page, but the normal state machine keeps requesting it forever.

Reachability is the advertised public service contract with canonical message publication and real renderer selection, not fabricated private storage or a synthetic codec. NUL cannot occur in OS argv; this report does **not** claim the stock CLI generates that prefix. Replacing prefix NUL with U+0001 preserves the expansion and is OS-argv legal, but the maximum actually generated executable/state/socket route was not proven here. The full admitted public prefix already establishes the implementation failure; native default-prefix reachability is a separate, unclaimed strengthening.

Effect at the actual consumer: `src/cli/watch.rs:655–730` performs V2 pull, validates/emits the page, and immediately continues when `page.more` is true. Cancellation/Close checks remain functional, but absent external canonical display/settlement removing the stuck head, normal delivery never drains and later small messages cannot pass it. Hooks repeatedly revisit the same pending work on later opportunities.

This is outside the explicit accepted render exceptions. The corresponding due/owner branches in `invitation_content.rs` implement finite progress. The ordinary 8 KiB inheritance alone cannot prove singleton renderability for every admitted prefix.

Add an actual admitted service/Watch regression that queues a later small canonical item, asserts bounded progress/quiet, and verifies no accidental ACK/read/acceptance or logical offer.
