## Inspected source

- Kernel boot id (ht-ma6i.44): `HostProcessTable::kernel_boot` reads `/proc/sys/kernel/random/boot_id` (or macOS `kern.bootsessionuuid`), trims it, bounds it to 64 bytes and caches it per process. The store writes `node_kernel_boot` once at start. Binding insert, touch and connect stamp `liveness_boot` from that row. `process_continuity::judge` compares the boot first: a different known boot is `Gone`, an unknown boot with a live process is `Unknown`. `shell_continuity::read` records nothing without a boot id. `judge` and the store queries (`shell_rival_exists`, `shell_candidate_stands`) filter on `kernel_boot`. This matches the task and TRUST-POLICY C1. The accepted limit for pre-upgrade bindings with a NULL `liveness_boot` is documented.
- Unread key capability (ht-ma6i.45): `PresentedKey` and `KeyCapability` replace the keyless fallback. `seat resolve`, `me init` and recipient allocation all read the key through `plain_resolve_key` / `own_pane_continuity_key` before the journal opens, so an unread capability refuses with `ServiceBusy` and sends nothing. In the hook, `PaneCall.key_capability` is a `OnceCell`. `reattach_and_install` reads the key before touching the journal. `probes_resolved_pane` returns `Err` for an unread capability, which maps to `Reattach::KeyUnread` and ends quietly. `LocalSocketClient::capabilities` now caches only a received list or a definitive no.
- Watch key (ht-ma6i.46): the comment changes only. The register.js comment, the `claim_own_seat` doc and TRUST-POLICY now give the same rule: the mod adds nothing, and the child presents the key it inherits.
- Session reattach binds a free key (ht-ma6i.47): `continuity_candidates` puts the key's seat first (`ORDER BY (s.id IS ?4) DESC`) before the cut-off at 2. `decide_continuity` binds a free presented key (`EnrollThenBind`/`Bind`) in the same transaction when the reattached seat holds no key. The new C1 row text describes this.
- Seat inspection (ht-ma6i.49): `SeatRetirementState::Final` is removed. `retirement_state` is emitted only for a frozen, reversibly retired seat. The text output prints the owner label before the first `:`.
- Schema delta 16 (unreleased; main still ends at 0015 and is only 2 doc commits ahead of base): `seat_shell_fingerprints.kernel_boot NOT NULL`, the `node_kernel_boot` singleton, `occupant_bindings.liveness_boot`. The `allocation_decisions` swap follows the 0012 pattern.
