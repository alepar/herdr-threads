[fix-regression]
  verdict: confirmed (reproduce ✓ / refute ✗-survived / ground ✓)
  evidence: src/daemon/lifecycle.rs:322-325 `struct Launched { child: Child, stderr }` holds a Child, not a pid, so "keeps the reported pid wherever it keeps the child pid today" names something that does not exist. ensure_running_with_timeout (~L553-578) calls `child.child.try_wait()`: a non-success status returns "daemon exited during startup (status)" with the log tail; a success is "A clean exit is a lost election ... launch again" (`launched = None; attempt = StartAttempt::new()`), after which `if launched.is_none()` runs `OwnerLock::acquire`.
