[lanes: correctness, premortem, hot-path-perf]
  verdict: confirmed (reproduce ✓ / refute ✗-survived / ground ✓)
  evidence: Query is `SELECT j.ingest_seq,substr(j.raw,1,8) FROM journal j WHERE j.apply_state='parked_layout' ORDER BY j.ingest_seq`.   fix-shape hint: Add `j.apply_state<>'applied' AND` to the predicate so the partial index applies, and return early from `promote_parked` when the build has no registered layouts.
